# Automation design

1. Describe the manual process and its volume; automate only steps that are repetitive and rule-based.
2. Build in **Zapier** (or the tool's own automation) **turned off**: trigger, filters, actions, error handling.
3. Test with sample data; check for duplicates, missing fields and loops.
4. Document it in the SOP: what it does, the owner, how to pause it.
5. Switch it on; review the first week of runs.
