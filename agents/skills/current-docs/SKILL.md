# Current docs, every time

Models' knowledge ages; tools change monthly. Before you write code, configuration or infrastructure:

1. **Find the current version** of each language, framework, SDK, provider and tool you will use: the **Context7** connector (any library, Terraform providers, Swift, Kotlin), **AWS Knowledge** (AWS services, What's New), **Microsoft Learn**, **Cloudflare Docs**, or the official site with `curl`/`WebFetch`.
2. **Read the docs for the exact API** you call, at that version. Copy patterns from the docs, not from memory.
3. **Pin** what you chose and say in your report which versions you used and where you checked.
4. If two sources disagree, the vendor's own docs win; say so.
