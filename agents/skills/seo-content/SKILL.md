# SEO and content

Connector: **Ahrefs** when on; otherwise public search.

- Keyword research: volume, difficulty and intent; pick topics the site can rank for; group by intent.
- One page per intent: a title under 60 characters, a meta description under 155, one H1, scannable headings, internal links.
- Write for people first: answer the question in the first paragraph, show expertise, cite sources.
- Technical checks: indexable, fast, mobile-friendly, structured data where it fits.
- Report: keywords chosen and why, the draft, and how to measure (rankings, clicks) in a month.
