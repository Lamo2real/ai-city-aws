# Support replies

1. Read the whole conversation and the customer's history (orders, past tickets) in **Intercom**, **Gorgias**, **Help Scout** or HubSpot.
2. Find the answer in the knowledge base or help center; never guess a policy, price or date.
3. Reply: thank them, answer the actual question first, give exact next steps, set expectations (when they will hear back), sign as the brand.
4. Plain words, no blame, no jargon; match the customer's language.
5. Save as a draft unless the goal lets the team send; tag the conversation (topic, product) for reporting.
