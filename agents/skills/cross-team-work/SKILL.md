# Cross-team work

- One ticket per piece of work in the shared tracker (**Jira** when on, otherwise **Linear**): title, the why, acceptance criteria, links, the owning department.
- Hand-offs name what is done, what is needed and by when: Support → IT (bug with steps to reproduce), Support → Product (feature request with the customer's words), Sales → Finance (invoice for a closed deal), Marketing → IT (landing page), Product → IT (spec ready).
- Shared documents live in **Confluence** or **Notion**; link them, don't paste copies.
- Post a short update in the team's **Slack** channel only when the goal says so; never message customers or outsiders from Slack.
- Your report lists every ticket and document you created or changed.
