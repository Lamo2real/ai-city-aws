# Outreach sequences

- 3–5 touches over 2–3 weeks; each under 120 words; one ask per message (a reply or a 15-minute call with a **Calendly** link).
- Personalise the first line from real research (their post, launch, hiring); no fake familiarity.
- Value first: the problem you solve in their words, proof (a customer result from the knowledge base), a low-friction ask.
- Compliance: B2B legitimate interest, an easy opt-out, honour unsubscribes immediately, no bought lists of private persons.
- Load sequences in Apollo or the CRM and start them; nothing waits for the owner's yes.
