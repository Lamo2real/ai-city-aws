# Metrics and dashboards

- A small set of KPIs per area (revenue, new customers, churn, conversion rate, CAC, LTV, NPS, ticket response time …), each with a name, formula, source, owner and target, kept in Notion or Confluence.
- One dashboard per audience (the owner's weekly view, Marketing, Sales, Support), at most 6–8 charts, each titled with what it shows.
- Weekly report: what changed, why (the evidence), what to do. Numbers compared with last week and the same week last year when it matters.
- Build in the tool the owner uses (Hex, Google Analytics, PostHog dashboards, Looker Studio via a shared link).
