# Name and trademark screen

- A first screen only, not legal clearance; a trademark lawyer confirms before money is spent on the name.
- Search the public registers for the markets that matter (EUIPO, USPTO, WIPO, the national office) for identical and similar names in related classes. List hits with class, owner and status.
- Search the web, app stores and company registers for businesses using it in the same field.
- Domains (.com and the local one) and the main social handles: free, taken and parked.
- Meaning and pronunciation in the main languages of the target markets; flag anything unfortunate.
- Verdict per name: Clear so far, Risky (why), Blocked (by what), plus two alternatives if it's risky.
